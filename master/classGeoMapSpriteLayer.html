Detailed Description

Batched screen-space marker layer: renders one identical sprite per model row as a single scene-graph geometry node (one draw call, no per-marker QObjects). Use instead of a Repeater of GeoMapItems for high-count marker types (e.g. camera trigger points).

The model must expose a QObject per row at Qt::UserRole (QmlObjectListModel contract) with a QGeoCoordinate "coordinate" property; alternatively set coordinates to a plain list of QGeoCoordinates. Markers clamp to the rendered terrain surface and are center-anchored at spriteSize pixels square, in both 2D and 3D camera modes. sprite must be a texture provider (an Item with layer.enabled or a ShaderEffectSource).
