Detailed Description

The display branch behind the session's tee: leaky queue ! valve [! decodebin3 ! video sink].

Takes the receiver's video sink, inserts decodebin3 once the source streams and links its pad to the sink, asking upstream for a keyframe so the picture starts soon. Decoding is reported from the first frame that reaches the sink. A failing or stalled decoder is replaced without touching the rest of the pipeline. The sink outlives the session: the branch holds a ref and takes it out of the pipeline again.

The queue drops the oldest frame when the decoder falls behind, so the tee (and with it the recording) never waits for the decoder. A decoder can't recover a dropped compressed frame, so after a drop the branch also drops delta frames until the next keyframe, which it requests: the picture freezes briefly instead of smearing for a whole GOP.

Threading: the receiver's worker, except the probes and the decoder's signal handlers (streaming threads), which hand their work to the worker through BranchContext::post().
