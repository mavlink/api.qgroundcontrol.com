true: several functions can run on the port at once, so each one is turned on or off separately

"None" first, then each function allowed on the port. "None" is left out while a function that can't be removed from its default port is on it. Function on the port, as an index into functionLabels. The first one if there is a conflict. Parallel to functionLabels: true if that function is on the port. Used for shared ports. Each function parameter that puts a function on the port, as "NAME = value" true: a function which always runs on this port unless it is assigned elsewhere is on it true: the baud rate parameter is being read from the vehicle true: some option parameters are being read from the vehicle
