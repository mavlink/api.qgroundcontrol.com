Detailed Description

LG290P(03) base-station configuration, from Quectel's LG290P(03)&LGx80P(03) GNSS Protocol Specification V1.1 (§§2.3.9, 2.3.15, 2.3.22–25, 2.3.28) and Base Station Mode Application Note V1.1 §3.2. Commands are PQTM sentence bodies, sent as "$<body>*hh\r\n"; the receiver answers "<name>,OK[,<values>]" or "<name>,ERROR,<code>".

Role and base settings take effect only once saved with SAVE and restarted with RESTART, so configuration reads them back after a restart before trusting them. It changes and saves them only with consent to persistent changes; with consent it first restarts, so it works from the saved settings rather than another client's unsaved ones. The note permits re-running an unchanged survey (RESTART_SURVEY) and restarting without saving.
