Detailed Description

One network video stream: connects to a URI, shows it in a QML VideoOutput and records it.

Intent-based: callers state what they want (setConfig(), setActive(), setVideoOutput(), startRecording()) and the receiver gets there on its own, restarting after a config change and reconnecting after a failure. Call every method on the GUI thread; every signal is emitted there.

Backends implement the protected on*() hooks, which run after the base stored the new value, and publish their state through the protected setters.
