◆ offsetPolygon()

QList< QPolygonF > QGCPlanarGeometry::offsetPolygon ( const QPolygonF & polygon,
double distance )
nodiscard

Offsets a planar polygon by distance. Positive distances expand the polygon. Corners sharper than 45 degrees are squared off rather than mitered, so the result stays near the requested distance. Output winding matches the input. Multiple polygons can be returned when an inward offset separates a concave polygon.

QList< QPointF > QGCPlanarGeometry::offsetPolyline ( const QList< QPointF > & polyline,
double distance )
nodiscard

Builds a directed parallel path. Positive distances offset to the left of travel. A path ending where it starts is closed, unless all its points lie on one line, and produces an explicitly closed output. The output is empty when an inward offset collapses the path or when a closed path crosses itself.
