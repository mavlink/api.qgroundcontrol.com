Detailed Description

The RTSP source GStreamer::SourceFactory::create() builds, with QGC's transport, latency and retransmission policy.

The video URIs GStreamer::SourceFactory::create() accepts, without GStreamer.

The H.264/H.265 setup the source factory gives the depayloaders and parsers it builds or parsebin plugs. gateOnParameterSets() (GstSourceFactory.h) is defined here too.

◆ create()

GstElement * GStreamer::SourceFactory::create ( const QString & uri,
const Config & config )

Build a source bin (source [+ tsdemux] [+ rtpjitterbuffer] + parsebin) for uri. Supported schemes: rtsp/rtspt, tcp:// (MPEG-TS), udp:// (H.264 RTP), udp265:// (H.265 RTP), mpegts:// (MPEG-TS over UDP). A UDP URI with port 0 listens on a free port.

Ghost pads on the returned bin are wired lazily; for rtspsrc/tsdemux/parsebin they appear only after upstream produces pads, so callers must connect any downstream pad-added handlers before transitioning to PLAYING.

Returns the source bin or nullptr on failure.

Holds an RTP H.264/H.265 depayloader's byte-stream output back until a full parameter set (SPS and PPS, plus VPS for H.265) has arrived, then emits the parameter sets together with the first slice and removes itself. create() applies it to every depayloader it builds or parsebin plugs; length-prefixed output is left alone.
