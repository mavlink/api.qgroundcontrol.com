Detailed Description

template<class Key, class Resource, std::size_t Capacity>
class GstHw::GstHwImportCache< Key, Resource, Capacity >

Bounded LRU cache for GPU import resources sized for the handful of buffers a decoder pool recycles: a flat array searched linearly, so lookups and inserts never allocate. Serves the AHardwareBuffer path (EGLImages) and the D3D12 path (staging resources).

Pinned entries (a frame bundle still samples them) are never destroyed: eviction skips them, and erase/clear park them until unpinned. Entries removed where destroyableHere rejects them (e.g. off the render thread that owns the GPU object) are parked as well; drainDeferred() destroys parked entries once both conditions allow it. Not internally synchronized — the caller serializes access.
