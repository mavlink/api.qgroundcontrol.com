Detailed Description

Records the video of a QMediaCaptureSession with Qt Multimedia's encoders: a USB camera's (UVCCameraController), or a stream's decoded frames fed in through a QVideoFrameInput (QtMultimediaVideoReceiver). The capture session records with mediaRecorder(), which outlives it: a session going away mid-recording makes it finish the file and report it.

start() records to "<file without suffix>.<suffix of the format used>", trying recordingFormats() in turn until one encodes. recordingStarted() follows once the first frame is encoded, or recordingFinished() with an error; a failed attempt leaves no file behind. Recordings carry their start time and VideoReceiver::recordingComment().

QList< QMediaFormat > QtVideoRecorder::recordingFormats ( QMediaFormat::FileFormat container,
QMediaFormat::VideoCodec codec = QMediaFormat::VideoCodec::Unspecified )
static

The formats start() tries for container, best first: codec where Qt can encode it, then H.264 and the other codecs Qt can encode here, down to software MPEG-2. In container where Qt can write it, else in another container. Qt counts a hardware encoder as encodable even where the hardware turns it down, hence the fallbacks.
