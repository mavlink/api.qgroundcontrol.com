Detailed Description

A pipeline's bus, handled from the thread the pump lives on.

A sync handler runs on the posting thread for what can't wait; every other message is popped on the pump's thread, which the bus's poll fd wakes up, as Qt's QGstBusObserver does. detach() removes the sync handler, waits until no call into it is in flight and flushes what is still queued: nothing the pipeline posts reaches either handler afterwards.
