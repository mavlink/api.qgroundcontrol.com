Detailed Description

Resolves the live QRhi* driving QGC's main scene graph so platform-specific GPU-handoff code (D3D11 device sharing, Metal device matching) can target the same device QRhi is rendering on.

Qt does not expose a global RHI accessor — QQuickWindow::rhi() is the only public API and requires a window with an initialized scene graph. This helper walks QGCApplication::mainRootWindow() lazily on each call.

QRhi * QGCRhiCapture::qrhi ( )
