Detailed Description

The self-test's media pipelines: decoding the embedded samples and recording and reading back a file.

The checks GStreamer::selfTest() runs for the boot test (–simple-boot-test), proving that the GStreamer runtime the app ships works: its plugins load, every feature's elements exist, H.264 (and H.265, given a decoder) decodes, MP4 and MKV record, and GIO has TLS and, where the bundle ships libproxy, proxy support. Each failed check is logged under Video.GStreamer.SelfTest, naming the element, plugin or file at fault.
