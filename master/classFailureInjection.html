Detailed Description

QML singleton backing the Failure Injection page.

  • Catalog: the MAVLink FAILURE_UNIT / FAILURE_TYPE enums, with display names derived by stripping the enum-name prefix.
  • Session state: the activity log and injected units, kept here because the page is destroyed and recreated on navigation. notifyActiveVehicle() clears them when the active vehicle changes.
