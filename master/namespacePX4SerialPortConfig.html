Detailed Description

PX4 assigns serial ports per function: each function has a parameter (MAV_0_CONFIG, GPS_1_CONFIG, ...) whose value is the port it runs on. These helpers invert that into a per-port view, working only from parameter metadata and values so they can be tested without a vehicle.

QList< ParamWrite > PX4SerialPortConfig::assignPort ( const QList< Function > & functions,
int portId,
const QString & functionParamName )

Writes which put functionParamName on portId. On a port which isn't shared it becomes the only function there, and an empty functionParamName clears the port. A function is never cleared from its default port, since Disabled would leave it running there. Empty if nothing changes or the function can't run on the port.
