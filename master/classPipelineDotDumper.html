Detailed Description

Writes a receiver pipeline's graph as Graphviz .dot files.

Threading: the receiver's worker only, since a dump walks the pipeline and writes to disk.

Returns tag as a file-name part: letters, digits, '-' and '_' only (anything else becomes '_'), at most 57 characters, never empty. A dump tag can then neither leave its directory nor make the file name too long.
