Detailed Description

VideoBackend on GStreamer: the only place the app reaches GStreamer's lifecycle from, in the only order it can run: prepareEnvironment() on the GUI thread, before gst_init() reads the environment; initialize() once, on any thread; then selfTest(), once initialized.

gst_init() can't be undone, so initialize() runs GStreamer's setup once: a later call returns the first one's outcome, and a failed setup isn't retried. The receivers are then Qt Multimedia's. The free functions in GStreamer.h, GStreamerEnvironment.h and GStreamerSelfTest.h do the work.
