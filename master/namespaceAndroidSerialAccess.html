◆ requestUsbPermission()

bool AndroidSerialAccess::requestUsbPermission ( const QString & portName)

Asks the user to let QGC open the USB device of this port, and returns whether it did. It does not for a port whose device QGC may open already or is not attached, nor for one that is not a USB port. The user answers later, and opening the port fails until then. Opening the port asks once for each time the device is attached; this asks whenever it is called, also after a denial, so call it only for a connection that the user has asked for.
