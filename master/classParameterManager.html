Refresh a set of parameters in a single batch with exponential-backoff retry.

Parameters
namesMix of exact param names and prefix patterns ending in '*' (e.g. "COMPASS_*"). Prefix entries are expanded against the known parameter set at call time. Duplicate names are deduplicated automatically.
notifyFailureWhen true (default), shows a single user-visible message if any parameters still fail to respond after all retry rounds.
