Detailed Description

Selects the one correction stream sent to vehicles and UDP forwarding, with freshness, priority and hold-down. Each source category follows one instance at a time; another instance takes over once it goes stale. Callers submit only valid frames. Selection calls take the monotonic time in milliseconds.
