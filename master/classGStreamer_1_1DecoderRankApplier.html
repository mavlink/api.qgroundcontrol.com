Detailed Description

Applies decoder rank plans (planRanks()) to the default registry. It remembers the rank each feature had before QGC first changed it, so a new option starts over from those rather than adding to the previous one. A feature named in GST_PLUGIN_FEATURE_RANK keeps the user's rank. One per process, as the registry is. GUI thread.
