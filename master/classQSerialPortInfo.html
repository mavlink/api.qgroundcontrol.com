Detailed Description

A serial port of the Android device, described as Qt Serial Port's class of this name describes one elsewhere. The ports are the USB serial ports that Java lists and, if the app says so (AndroidSerialAccess), the serial device nodes.

QList< QSerialPortInfo > QSerialPortInfo::posixPorts ( const QString & devDir,
const QString & sysTtyDir,
const QList< QSerialPortInfo > & usbPorts = {} )
static

The serial device nodes in devDir that QGC may read and write: the device's own UARTs and the USB serial adapters that the kernel drives. sysTtyDir is the kernel's /sys/class/tty, which names the ports that have a driver, tells a UART without hardware and describes the adapters. The node of an adapter that usbPorts has a port of is left out, so that no device is listed twice.

QString QSerialPortInfo::stableName ( ) const
inline

A name that still opens the port after its USB device is unplugged and plugged back in, which gives it another portName(). Pass it to QSerialPort::setPortName(). Empty if the port has no such name: until the user lets QGC open the device, and for a device node, whose portName() does not change. Qt Serial Port has no such name.
