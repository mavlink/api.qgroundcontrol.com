◆ map()

QAbstractVideoBuffer::MapData GstHwVideoBuffer::map ( QVideoFrame::MapMode mode)
override

CPU view of the sample through gst_video_frame_map (e.g. GL memory downloads, DMABuf mmaps). Qt's createTextures() uploads this whenever mapTextures() fails, so a failed GPU import still shows the frame. ReadOnly only. Refused when format() advertises another pixel format than the memory holds: Qt would upload it in the wrong format or read past it.

◆ refSample()

GstSample * GstHwVideoBuffer::refSample ( )
inlinenoexcept

New sample ref for the texture bundle built in mapTextures(). The buffer keeps its own ref so map() and a repeated mapTextures() (another window, QRhi re-creation) still find the sample; Qt keeps this frame alive alongside the bundle anyway (QVideoFrameTextures::setSourceFrame), so no buffer is held longer.
