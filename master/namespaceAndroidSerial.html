Detailed Description

The USB serial ports of the Android device, as QGCUsbSerialManager.java provides them. A function that calls a Java method has the name of that method.

What the app itself uses of AndroidSerial, the USB serial ports of the Android device as Java provides them: it binds Java's callbacks as the library loads, tests that binding at boot, and hears when the devices change. AndroidSerialJni.h declares the rest of the namespace, which is private to the serial port library.

◆ open()

int AndroidSerial::open ( const QString & portName,
PortHandle handle )

Opens the port under a handle from registerPort(). Returns the file descriptor of the port's USB connection, which is not negative, or a Result. For a device that still needs USB permission the result is one of the five Permission results, which tells what has become of the permission, and getLastErrorDetail() has nothing to add to it. Such an open also asks the user for the permission, who answers later; DeviceWatcher tells of the answer. Callers open ports without being told to and try again every few seconds, so the open asks once for each time the device is attached, not in the first seconds after that, which Android's own prompt for the device takes to appear, and only while QGC's window has the focus. It asks once more if Android closes the dialog without an answer. After a denial, the user is asked again once the device has been replugged, or by requestPermission(). A stable name that no device with permission has stands for the only attached device with its vendor and product IDs that still needs permission, if there is exactly one.
