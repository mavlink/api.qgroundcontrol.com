◆ configureQtGraphics()

void HwBuffers::configureQtGraphics ( bool softwareRendering)

Qt graphics setup the GPU paths need, which Qt reads at startup: call before the QGuiApplication exists. On desktop Linux it pins the scene graph to OpenGL, unless softwareRendering (–swrast) or QSG_RHI_BACKEND chose one, and Qt's xcb platform to EGL; with the GL or DMABuf path it shares Qt's OpenGL contexts, and with the DMABuf import under Vulkan it asks for the device extensions that takes, should Qt Quick render with Vulkan. No-op otherwise.
