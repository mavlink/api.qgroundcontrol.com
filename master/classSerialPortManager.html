◆ requestAccess()

bool SerialPortManager::requestAccess ( const QString & name)

Asks the user to let QGC open the port, and returns whether it did. It does not for a port that has access already, that takes no permission, or whose device is not attached. The user answers later, and the port does not open until then; a scan of the ports follows a grant. Opening a port asks by itself, once for each time its device is attached. This asks whenever it is called, also after a denial, so call it only for a connection that the user has asked for.
