◆ d3d11OpensD3D12

bool GStreamer::RankTraits::d3d11OpensD3D12 = false

Windows, Direct3D 11: Qt's device opens a Direct3D 12 device's resources (HwBuffers::d3d11OpensD3D12()). The d3d12 decoders are then the ones preferred, as GStreamer ranks them: they decode on a device of their own, not on the one Qt draws with. The d3d11 ones keep GStreamer's rank, behind them.

◆ preferZeroCopyDecoders

bool GStreamer::RankTraits::preferZeroCopyDecoders = false

Linux: for the default and hardware options, rank the va and v4l2sl decoders, which output DMABuf, above every other. The default option also demotes the legacy vaapi decoders, whose memory the GPU paths can't import; the hardware option keeps them below as a fallback.

◆ rhiAdapterLuid

◆ softwareRendering

bool GStreamer::RankTraits::softwareRendering = false

The user asked for software rendering (–swrast, the GPU Safe Mode shortcut), to keep off a GPU or driver that misbehaves. Qt samples no decoder's GPU frame then: with the default option every hardware decoder ranks below the software decoders. A decoder option the user chose stays as it is.
