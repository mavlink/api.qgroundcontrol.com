Detailed Description

Finalization of the active recording, settled by the first of: the recorder's EOS (closed) or a recorder ERROR (failed). Armed with the recording's file sink, so messages about an earlier file can never settle the current one.

Threading: the receiver's worker only; the bus messages that settle it are handled there.
