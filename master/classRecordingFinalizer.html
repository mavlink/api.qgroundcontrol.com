Detailed Description

Finalization of the active recording, settled by the first of: splitmuxsink-fragment-closed or a branch/pipeline EOS (closed), or a recorder ERROR (failed). Armed with the recording's file sink, so messages about an earlier file can never settle the current one.

Threading: settled from the bus handler on whichever thread posts; armed, disarmed and waited on by the worker.
