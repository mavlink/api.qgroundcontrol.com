Detailed Description

Controller for PX4BatteryComponent.qml. PX4 only streams the parameters a running module has looked up, such as a power monitor driver's settings once the driver runs, so the page requests the rest by name.

int PX4BatteryController::addedParamCount ( ) const
inline

Number of parameters the vehicle has added since the page opened, requested or not. Changes once the new parameter has its value and is ready, and before pendingParams signals the change, so bindings on it have updated by then. A failed read does not change it.

◆ requestParameters()

void PX4BatteryController::requestParameters ( const QStringList &  names)

Requests each named parameter the vehicle has not sent. A name stays in pendingParams until its value arrives or the read fails. Parameters the firmware does not have are dropped without telling the user, and are not requested again for the same vehicle.
