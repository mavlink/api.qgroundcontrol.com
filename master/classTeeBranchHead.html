Detailed Description

The tee ! queue ! valve head every tee branch starts with.

Built closed (the valve drops frames) and marked as one GStreamer::PipelineBranch, so bus messages from it are blamed on that branch. A branch opens the valve once it has linked what follows it, which then starts from the keyframe open() asks upstream for, and closes it again before taking that out. The pipeline owns both elements.

Threading: the receiver's worker, except the overrun handler (streaming threads).
