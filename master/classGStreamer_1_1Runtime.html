Detailed Description

GStreamer's process lifecycle, in the only order it can run: prepare() the environment on the GUI thread, before gst_init() reads it; initialize() once, on any thread; then selfTest(), once initialized.

gst_init() can't be undone, so initialize() runs GStreamer's setup once: a later call returns the first one's outcome, and a failed setup isn't retried. Owned by GStreamerVideoBackend, the app's only way to GStreamer's lifecycle; the free functions in GStreamer.h do the work.
