Detailed Description

Septentrio receivers configured as RTK bases with SBF commands; they stream PVTGeodetic blocks and RTCM3.

Offsets count from a block's first sync byte, so a whole block decodes directly. Each layout ends at the last field QGC reads, which is the shortest block QGC can decode.
