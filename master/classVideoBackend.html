Detailed Description

The network video backend this build has, behind which callers (VideoManager, VideoSettings, QGCCorePlugin, the platform startup code) never name a concrete one: GStreamer, or, without it, Qt Multimedia's player (QtMultimediaVideoReceiver), which a GStreamer build also offers through VideoSettings::videoBackend.
