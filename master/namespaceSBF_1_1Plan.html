Detailed Description

Septentrio base-station configuration as command lists, in the order the receiver gets them. The receiver echoes an accepted command as "$R: <command>" and answers a rejected one with "$R?"; each attempt waits up to one second. Commands address the connection descriptor the receiver reported, such as USB1, COM1 or IP10.
