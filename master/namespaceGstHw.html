◆ buildSupportedDmaDrmCaps()

std::string GstHw::buildSupportedDmaDrmCaps ( std::span< const GstVideoFormat > formats,
void * display )

Best-effort DMA_DRM caps string built from the (format, modifier) pairs EGL display (Qt's EGLDisplay, as HwBuffers::dmaBufImportDisplay() returns it) reports, intersected with formats: a pair is offered when Qt's DMABuf importer can sample every plane of the format with that modifier (no compression or auxiliary planes). Returns a single ready-to-prepend "video/x-raw(memory:DMABuf), format=DMA_DRM, drm-format={ FMT:0xMOD, ... }; " fragment, or "" on ANY failure (null display, no modifier query). Additive only: callers must keep the existing system catch-all.

True when a native texture of textureSize holds picture in its top-left corner with padding around it: decoders pad their surfaces to their alignment without crop meta. evenSizes: the texture format (4:2:0) only has even sizes, so an odd picture dimension rounded up is no padding.
