Best-effort DMA_DRM caps string built from the GPU's EGL-reported (format, modifier) pairs intersected with formats. Returns a single ready-to-prepend "video/x-raw(memory:DMABuf), format=DMA_DRM, drm-format={ FMT:0xMOD, ... }; " fragment, or "" on ANY failure (no display/ext/results/error). Additive only: callers must keep the existing system catch-all.
