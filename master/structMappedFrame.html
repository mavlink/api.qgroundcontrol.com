Detailed Description

Sample-to-frame result (GPU wins when it can, CPU fallback). mapSampleToFrame() does NOT take the caller's refs on buffer/caps: a GPU frame holds its own GstSample, a zero-copy CPU frame its own buffer ref. A frame no GPU path takes whose layout the CPU can't read (a tiled DMA_DRM modifier) comes back invalid, with noCpuLayout set.
