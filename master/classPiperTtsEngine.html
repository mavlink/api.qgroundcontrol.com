Detailed Description

Text-to-speech engine backed by a system-installed Piper (https://github.com/OHF-Voice/piper1-gpl). Piper is GPL-licensed, so it is only ever run as a separate process and never linked or bundled. One Piper process is kept running so the voice model is loaded once, not per utterance.
