Detailed Description

UM980/UM982 base-station configuration as command lists, in the order they are sent, from the Unicore N4 Commands and Logs Reference Book EN R1.6 (sections 3, 7.3.1, 7.3.27 and 7.3.44). Each command is one "<text>\r\n" line for the current port. Nothing is saved: the plan never sends SAVECONFIG or FRESET.
