const GPSReceiverFamily FAMILY

Detailed Description

Read-only input from a receiver configured elsewhere: standard NMEA, u-blox UBX or Septentrio SBF, whichever the receiver sends, and RTCM3. Configuration only sets the local link's baud rate and never sends a receiver command.
