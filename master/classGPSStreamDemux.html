Detailed Description

Routes each received byte to the framers of one stream.

Every enabled framer claims each byte: Locked while it is inside a frame, Owns for a sync byte that starts one of its frames, Watch for a sync byte it only observes, Default when it accepts any byte (the text framers), or None. A Locked framer, else the first framer that Owns the byte, receives it alone and resets every other framer. Otherwise the watching framers and the first Default framer all receive it. Precedence is RTCM3, UBX, SBF, NMEASentence, ASCIILine.

This reproduces the per-family routing: RTCM3 interrupts text framers mid-line (ASCII families, Femto), while a UBX or SBF frame in progress keeps its bytes, including embedded 0xD3 preambles, and RTCM3 only takes bytes between native frames.
