Detailed Description

◆ buildGpuCapsString()

std::string GstQgc::buildGpuCapsString ( HwBuffers::GpuBinMode  mode)

Builds the format capsfilter caps for the gpu-zerocopy bin of mode, branching on the compiled GPU paths. The glupload bin takes GLMemory only; the others take every compiled native memory plus system memory, and the direct DMABuf bin leaves GLMemory out. DMABuf builds also query EGL for importable DMA_DRM modifiers and read QGC_GST_OFFER_DMA_DRM_LINEAR.
