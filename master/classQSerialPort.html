class AndroidSerialBackendHost

Detailed Description

The serial port of QGC on Android. Qt Serial Port's own opens device nodes only, and Android lets an app reach a USB serial adapter through its USB API alone. This class has the name and the interface of Qt Serial Port's, so that code which uses a serial port is the same on every platform and includes <QtSerialPort/QSerialPort>. Of that interface it leaves out the properties and their bindables, and a baud rate for one direction only.

The port's name decides what it opens (AndroidSerialBackend): a USB serial adapter, which Java drives, or a serial device node. Input arrives on other threads and is announced on the port's own, which is the only one that may call the port.
