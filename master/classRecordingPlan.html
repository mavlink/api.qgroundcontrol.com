Detailed Description

What a receiver was asked to record, across the sessions reconnects start.

Owns VideoReceiver::startRecording()'s file contract for a receiver that records the stream as it arrives: the first session records to the file asked for, and each later one, once the part before got frames, to "<base>_part<N>.<ext>", N counting from 2. A receiver that encodes the frames anew keeps one part. Also tells the recording's time and size for VideoStreamStats.
