Detailed Description

What a receiver was asked to record, across the sessions reconnects start and the hours it runs for.

Owns VideoReceiver::startRecording()'s file contract for a receiver that records the stream as it arrives: it starts in the file asked for and continues in "<base>_part<N>.<ext>", N counting from 2, after each session that got frames and whenever a part has recorded for kMaxPartDuration. A receiver that encodes the frames anew keeps one part. Also tells the recording's time and size for VideoStreamStats.

std::chrono::minutes RecordingPlan::kMaxPartDuration {60}
staticconstexpr

How long a part records before the next one takes over. It bounds what a file holds, for the storage limit to remove a long recording's oldest parts, and what an MP4 or MOV muxer must reserve header space for.
