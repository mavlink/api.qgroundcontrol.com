Detailed Description

The VideoStreamStats a receiver publishes, sampled about once a second while it streams.

The backend fills the fields only it can measure and counts what VideoStreamStatsMeter turns into rates; the sampler adds the fields every backend reports alike: uptime and reconnects from the receiver's StreamSupervisor, and the recording's time and size from its RecordingPlan. It keeps the stats it last produced, so a receiver publishes changes only.
