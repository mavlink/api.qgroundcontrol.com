Detailed Description

Common base for per-platform FrameTextures : QVideoFrameTextures from *VideoBuffer::mapTextures(). Qt invokes onFrameEndInvoked() on the current bundle after every window frame and keeps sampling it until its pool slot is reused, so the source sample and every native resource must live until destruction — never release them from onFrameEndInvoked().

Wraps one native handle per plane (GL name, VkImage, ID3D1x resource, MTLTexture) as a QRhiTexture and records the import for matchesImport(). Fallback formats are disabled: a substituted format would misread the native layout. Planes QRhi rejects stay null, as do zero handles (a plane the source never produced), whatever the QRhi backend's createFrom() accepts.
