Detailed Description

The recording branch behind the session's tee: queue ! valve [! parser ! muxer ! filesink].

Records the requested file from the next keyframe once the source streams, asking upstream for that keyframe, and finalizes it within kFinalizeTimeout when the request goes away or the pipeline is torn down. MP4/MOV are muxed so a crash leaves the file playable up to the last header update. A failing recorder (disk full, storage too slow to keep up) ends the recording, not the stream: its queue holds kQueueMaxBytes of backlog and then stops taking frames rather than holding up the tee and with it the display.

Threading: the receiver's worker, except the probes and the queue's signal handler (streaming threads), which hand their work to the worker through BranchContext::post().
