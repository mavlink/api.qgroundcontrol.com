Detailed Description

The recording branch behind GstVideoReceiver's tee: queue ! valve [! parser ! splitmuxsink].

Builds a file sink per recording, starts the file at the first keyframe, and finalizes it on stop within kFinalizeTimeout. A failing recorder ends the recording, not the stream. Reports through the receiver's signals.

Threading: the onBus*() methods run on whichever thread posts, the keyframe probe on the streaming thread, and everything else on the receiver's worker.

◆ finishForTeardown()

void RecordingBranch::finishForTeardown ( )

Before the pipeline is torn down: drains an active recording into its file, then waits up to kFinalizeTimeout for the file (or one stop() is finalizing) to be closed. A recording that has no frame yet, or whose file failed or didn't close in time, is dropped instead.
