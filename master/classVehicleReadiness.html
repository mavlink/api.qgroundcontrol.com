Detailed Description

Whether the vehicle would accept the Arm, Takeoff and Start Mission guided actions.

This is the single source of readiness for both the guided actions and the toolbar status. It is created by FirmwarePlugin::createVehicleReadiness, since the firmware plugin decides which flight modes each guided action arms and runs in. Every action is locked out until initial connect completes. After that readiness uses the best source available on the vehicle:

  1. libevents health and arming checks (mode aware: arming checks while disarmed, mode requirements while armed)
  2. The SYS_STATUS prearm check bit (current mode only)
  3. SYS_STATUS sensor health and vehicle setup, which only feeds the pre-flight status and never blocks actions Readiness is a prediction. The vehicle has the final say on every command.
